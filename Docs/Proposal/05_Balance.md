## 1. 설계 목표
| 목표 | 기준 수치 | 근거 |
|---|---|---|
| 콤보를 지키면 크게 보상 | 연속 Hit 7점 = 첫 Hit 5점의 1.4배 | 콤보가 끊기면 손해가 바로 느껴짐 |
| Miss 1번은 만회 가능 | Miss -4 < 연속 Hit 1번 +7 | 실수해도 다음 노트로 회복 |
| 연속 실수는 끝 | 연속 Miss 3번 = GAME OVER | 긴장감 |
| 레벨이 곡 안에서 3 ~ 4번 오름 | 200 → 400 → 800 → 1600 | 아래 계산으로 검증 |

## 2. 점수 규칙 (`score_rules.csv`)
```
Hit  : 점수 += (COMBO ≥ 2 ? 7 : 5)
Miss : 점수 = max(0, 점수 - 4)
레벨 : 점수가 200, 400, 800, 1600 … 에 닿을 때마다 +1 (점수가 내려가도 유지)
GAME OVER : Miss 직후 (점수 ≤ 0 OR 연속 Miss ≥ 3), 또는 노래 끝
```

## 3. 계산 — 곡별 최대 점수 · 레벨 (`beatmap_stats.csv`)
```
최대 점수(모두 Hit) = 5 + (노트 수 - 1) × 7
레벨 2(200점)까지 필요한 연속 Hit = 1 + 올림((200 - 5) ÷ 7) = 29개
```
| 곡 | 난이도 | 노트 | 최대 점수 | 도달 레벨 | 카운트다운에 건너뛰는 노트(최소) |
|---|---|---|---|---|---|
| Club Change Up | Normal | 158 | 1,104 | 4 | 4 |
| | Hard | 192 | 1,342 | 4 | 2 |
| | Expert | 359 | 2,511 | 5 | 4 |
| Echoes of Lumen | Normal | 160 | 1,118 | 4 | 0 |
| | Hard | 216 | 1,510 | 4 | 2 |
| | Expert | 453 | 3,169 | 5 | 3 |
| Upbeat Funk | Normal | 144 | 1,006 | 4 | 0 |
| | Hard | 181 | 1,265 | 4 | 1 |
| | Expert | 248 | 1,734 | 5 | 3 |

> 건너뛰는 노트는 "첫 2초(READY · GO!) 안의 노트" 기준 최소값이에요. 실제로는 이동 시간만큼 더 앞의 노트도 건너뛰어서 느린 Normal일수록 더 많아요.

**해석**
- 모두 Hit해도 Normal · Hard는 레벨 4, Expert는 레벨 5에서 끝 → **레벨 차이가 거의 없음** (난이도 보상이 약함)
- 레벨 2까지 29연속 Hit → Normal(약 2개/초)에서 **약 15초** 걸림. 첫 레벨업이 늦음

## 4. GAME OVER 위험 계산
```
시작 직후 첫 노트 Miss → 0 - 4 → 0점 → GAME OVER (조건 ②)
첫 Hit 1번 후 Miss → 5 - 4 = 1점 → 다음 Miss면 0점 → GAME OVER
→ 처음 두세 노트 안에 Miss 2번이면 무조건 끝
```
| 시나리오 | 결과 | 💡 제안 적용 후 (시작 점수 20) |
|---|---|---|
| 첫 노트 Miss | 즉시 GAME OVER | 16점 — 계속 |
| Hit → Miss → Miss | 1 → 0 → GAME OVER | 21 → 17 → 13 — 계속 |
| Miss 3연속 | GAME OVER | GAME OVER (연속 3번 규칙은 유지) |

## 5. 💡 제안 — 레벨 기준을 콤보로
점수는 Miss로 내려가서 레벨 기준으로 쓰기 불안정함 → **최대 콤보** 기준으로 바꾸면 곡과 상관없이 같은 느낌:

| 레벨 | 현재 (점수) | 제안 (최대 콤보) | Normal 2개/초 기준 도달 시간 |
|---|---|---|---|
| 2 | 200 (29연속) | 10 | 5초 |
| 3 | 400 | 25 | 12.5초 |
| 4 | 800 | 50 | 25초 |
| 5 | 1,600 | 100 | 50초 |
