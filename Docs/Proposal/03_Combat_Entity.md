# 03. 베기 · 개체 상세 기획서 (칼 · 노트 · 판정 연출)

> 문서 세트: [목차](Proposal.md) · [01 컨셉](01_Concept.md) · [02 시스템](02_System.md) · **03 베기·개체** · [04 레벨 디자인](04_LevelDesign.md) · [05 밸런스](05_Balance.md)
> 리듬 게임이라 가이드의 "전투" 자리에 **핵심 조작(베기)과 상호작용 개체(칼 · 노트)**의 명세를 담았어요.

---

## 1. VR 조작 방식
| 손 | 칼 색 | 벨 수 있는 노트 | 조작 |
|---|---|---|---|
| 왼손 | 빨강 | 빨강 노트 | 컨트롤러 위치 · 움직임 그대로 |
| 오른손 | 파랑 | 파랑 노트 | 〃 |
| 메뉴 | 레이 + 트리거 | – | 곡 `<` `>` · 난이도 · START · RESTART · HOME · 설정 |

| VR 편의 | 설계 |
|---|---|
| 멀미 | 플레이어는 제자리, **노트가 다가오는** 구조 → 카메라 이동 없음 |
| 박자 동기화 | 오디오 시계 기준 예약 재생 (+0.1초), 보정값(`_timingOffset`)으로 기기별 지연 조절 |
| 시야 | 180도 배경 영상으로 공간감, 노트는 정면 좁은 범위(가로 0.6m · 세로 0.5m 간격)에만 |

## 2. 칼 명세 (`Saber` · `HitZone`)
| 항목 | 값 |
|---|---|
| 길이 | 2.0m (레이캐스트) |
| 최소 휘두르기 속도 | 0.5 m/s (이보다 느리면 판정 안 함) |
| 방향 판정 | 휘두른 방향과 노트 위쪽 사이 각도 **130도 초과** |
| 연출 | 레인보우 트레일 (`RainbowTrailFollower`) |

**칼 위치 판정 구간**
```
손(0m) ─────────── 1.0m ──── 1.2m ────── 1.5m ──────────── 2.0m(끝)
│        MISS        │ GREAT │ MARVELOUS │      PERFECT      │
```
| 구간 | 판정 | 결과 | 의도 |
|---|---|---|---|
| 0 ~ 1.0m | MISS | Miss | 손 가까이로 "막는" 동작이 아니라 크게 휘두르게 |
| 1.0 ~ 1.2m | GREAT | Hit | |
| 1.2 ~ 1.5m | MARVELOUS | Hit | |
| 1.5 ~ 2.0m | PERFECT | Hit | 칼끝 = 가장 큰 동작 = 최고 판정 |

## 3. 노트 명세 (`Note` · `NoteSpawner`)
| 항목 | 값 |
|---|---|
| 색 | 빨강(type 0) · 파랑(type 1) — 폭탄(3)은 제외 |
| 방향 | 8방향 + 아무 방향(Any) — 화살표로 표시 (회전 각도) |
| 위치 | 줄(가로, 0.6m 간격) × 층(세로, 0.5m 간격, 바닥 -0.39m) |
| 속도 | Normal 3 · Hard 5 · Expert 8 m/s |
| 놓침 | 플레이어를 1m 지나면 MISS |
| 판정 후 | 한 번만 판정 → 사라짐 (Hit이면 맞는 이펙트) |

## 4. 판정 문구 · 피드백
| 문구 | 조건 | 점수 | 연출 |
|---|---|---|---|
| `PERFECT` | 칼끝 1.5 ~ 2.0m | 첫 +5 / 연속 +7 | 노트 자리에 떠올랐다 사라짐 (색 · 크기 · 시간은 `EffectManager`에서 조절) |
| `MARVELOUS` | 1.2 ~ 1.5m | 〃 | 〃 |
| `GREAT` | 1.0 ~ 1.2m | 〃 | 〃 |
| `MISS` | 손잡이 쪽 · 방향 틀림 · 놓침 | -4 | 〃 |
| `READY` · `GO!` | 시작 | – | 1초씩 |

### 💡 제안 — 판정별 점수 차등
| 판정 | 현재 (첫 / 연속) | 제안 (첫 / 연속) | 이유 |
|---|---|---|---|
| PERFECT | 5 / 7 | 7 / 10 | 칼끝 판정이 점수로 이어져야 "정확히 벨 동기"가 생김 |
| MARVELOUS | 5 / 7 | 5 / 7 | 기준 |
| GREAT | 5 / 7 | 3 / 5 | |

### 💡 제안 — 장애물 노트
| ID | 이름 | 동작 | 등장 |
|---|---|---|---|
| `OBS_BOMB` | 폭탄 | 베면 Miss (비트맵 type 3 그대로 활용) | Hard ~ |
| `OBS_WALL` | 벽 | 머리를 숙이거나 옆으로 피해야 함 | Expert |

## 5. 이펙트 · 사운드 요구사항
| 대상 | 이펙트 | 사운드 | 현재 |
|---|---|---|---|
| 칼 | 레인보우 트레일 | – | ✅ |
| 노트 Hit | 맞는 이펙트 (`EffectManager.PlayHit`) | 노트 맞는 소리 | ✅ |
| 판정 | 판정 문구 팝업 (`GradePopup`) | – | ✅ |
| 점수 | 점수 피드백 (`ScoreFeedback`) | – | ✅ |
| 버튼 | 누름 · 선택 피드백 | 클릭 소리 | ✅ |
| 배경 | 180도 영상 | 선택한 곡 | ✅ |
| 콤보 10 · 50 · 100 | – | – | 💡 칼 트레일 색 · 굵기 변화 + 짧은 효과음 |
| GAME OVER | 패널 | – | 💡 노래 감속(피치 다운) 연출 |
