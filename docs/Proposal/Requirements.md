## 4. 완료 기준 (Given / When / Then)
| ID | 완료 기준 |
|---|---|
| `REQ_101` | Given 곡 시작 / When 첫 노트를 놓쳐도 / Then 게임은 계속되고, 체력이 0이 될 때만 GAME OVER |
| `REQ_102` | Given 마지막 노트까지 / When 노래가 끝나면 / Then "CLEAR!"와 랭크 · 정확도 · 최대 콤보가 보인다 |
| `REQ_104` | Given 플레이 중 / When 헤드셋을 벗으면 / Then 노래와 노트가 함께 멈추고, 다시 쓰면 3초 카운트다운 뒤 박자가 맞게 이어진다 |
| `REQ_107` | Given 보정 화면 / When 박자에 맞춰 8번 누르면 / Then 평균 오차가 `_timingOffset`에 저장된다 |
