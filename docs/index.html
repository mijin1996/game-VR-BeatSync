🎮 조작 방법

노트가 보라색 선에 닿는 순간, 노트의 화살표 방향 키를 누르세요.

오른쪽 패널 [START] / Space
시작 (READY · GO! 뒤에 노트가 내려와요)
W A S D
왼손 — 빨강 노트 (W=↑ A=← S=↓ D=→)
↑ ← ↓ →
오른손 — 파랑 노트

💡 노트는 실제 곡의 악보(Beat Sage 비트맵) 그대로예요. 빨강 노트는 W A S D, 파랑 노트는 방향키 — 노트가 왼쪽 · 오른쪽 어느 줄에 오든 색으로 손을 고르세요. 대각선 노트는 두 방향 중 아무 키나(예: ↖ = W 또는 A), 점(Any) 노트는 아래 키예요. 첫 노트를 놓치면 바로 GAME OVER예요 (실제 게임 규칙). 키가 안 먹으면 게임 화면을 한 번 클릭하세요.

판정 기록

칼 위치 판정(칼끝 1.5~2m = PERFECT …)은 키보드로 재현할 수 없어서 타이밍 구간으로 옮겼어요. ±60ms PERFECT · ±110ms MARVELOUS · ±160ms GREAT · 그보다 벗어나면 MISS(칼 손잡이 쪽에 맞은 것과 같은 취급).
